11  Reading the Air

A tutorial on air quality statistics of a city.

In this tutorial, we will take a monitoring data from a single city (Addis Ababa) and perform basic data analysis required to read the air quality of the city in an informed way.

11.2 City Hourly Statistics

A city’s hourly average PM2.5 is measured as the average of PM2.5 concentrations reported at all stations in the city.

city_hourly = data.groupby(['year','day_of_year','hour'])[['pm2.5']].mean().reset_index()
city_hourly = city_hourly.rename(columns = {'pm2.5':'pm25_avg'})
city_hourly.head()

Its obvious that at a given hour, different stations report different concentrations. The variation between these concentrations is also an useful measure. Its also useful to know the number of stations used to calculate these statistics.

city_hourly['pm25_std'] = data.groupby(['year','day_of_year','hour'])[['pm2.5']].std().reset_index()['pm2.5']
city_hourly['num_stations'] = data.groupby(['year','day_of_year','hour'])[['pm2.5']].count()['pm2.5'].reset_index()['pm2.5']

11.3 City Daily Statistics

When we have station hourly data, it is better to use that to calculate city daily statistics. If we use city hourly averages to calculate daily average, each hour’s average gets equally weighted. But we know that if an hour’s average is calculated from more number of stations, it is better. Hence, City average PM2.5 concentration on any day is the average of all station hourly values on that day.

city_daily = data.groupby(['year','day_of_year'])['pm2.5'].agg(['mean','std','count']).reset_index()

import geopandas as gpd
import contextily as cx
import matplotlib.pyplot as plt

# df has: station, lat, long, mean
gdf = gpd.GeoDataFrame(
    station_annual,
    geometry=gpd.points_from_xy(station_annual["Long"], station_annual["Lat"]),
    crs="EPSG:4326",
)

# Buffer in a local metric CRS (UTM) so 2000 m is accurate,
# then reproject to Web Mercator for the basemap
utm = gdf.estimate_utm_crs()
circles = gdf.to_crs(utm).copy()
circles["geometry"] = circles.geometry.buffer(2000)   # 2 km radius
circles = circles.to_crs(epsg=3857)

fig, ax = plt.subplots(figsize=(10, 10))
circles.plot(
    column="mean",
    cmap="YlOrRd",
    alpha=0.6,
    edgecolor="black",
    linewidth=0.5,
    legend=True,
    legend_kwds={"label": "Annual Mean PM2.5 (µg/m³)", "shrink": 0.6},
    ax=ax,
)

cx.add_basemap(ax, source=cx.providers.Esri.WorldStreetMap)   # no key
ax.set_axis_off()
plt.tight_layout()
plt.show()

Each station represents a circular area of about 2km radius. We can thus see that the monitor network is not well distributed.
